# 📌 Dynamic Multi-Category Todo App

A modern, high-performance, and responsive Task Management application built from scratch using vanilla web technologies. This project showcases dynamic DOM manipulation, advanced JavaScript array/object operations, and persistent state management.

---

## ✨ Features

- **Dynamic Category Mapping**: Automatically applies distinct visual branding and border highlights based on user-selected categories (Personal, Work, Shopping, Health).
- **Advanced State Management**: Implements structured JavaScript arrays and objects to create, track, and filter items on the fly.
- **Hardware-Layer Persistence**: Utilizes browser `LocalStorage` so your tasks remain securely stored even after a page refresh.
- **Modern User Experience**: Features functional animation states, validation checks, and clean semantic element structure.

---

## 🛠️ Built With

- **HTML5**: Semantic elements (`<header>`, `<main>`, `<form>`) for optimal accessibility.
- **CSS3 Modern Specs**: Custom structural layout powered by CSS Variables, custom view-port resets, and smooth UI keyframe animations.
- **Vanilla JavaScript (ES6+)**: Features modern data architectures including `crypto.randomUUID()`, `Array.prototype.forEach()`, and `Array.prototype.filter()`.

---

## 🚀 How to Run Locally

1. Clone or download this repository to your local system.
2. Navigate into the project folder.
3. Open the `index.html` file directly in any modern web browser.
